DayTodo Android 1.1（优化版原型）
按天显示的轻量清单，未完成任务自动顺延到今天。

可交互原型：点底部导航切页 · 点日期胶囊切换日期 · 点圆圈完成 · 点 ⋯ 打开操作面板 · 点 + 新建 · 点日期标题开日历
Esc 关闭面板

1现状诊断

读现有 1288 行 Compose 实现后的问题清单，按影响面排序。

现状：顶栏+Tab+日期头
三层叠在顶部，底部常驻输入区
字号 10–12sp
信息层级顶栏 / Tab / 日期头 / 列表 / 常驻输入条，5 层挤在一屏
正文字号任务标题 12sp、标签 10sp、辅助 10sp —— 远低于移动端 14sp 基线
触控目标日期左右箭头仅 24dp、更多按钮 28dp，远低于 44dp 最小触控
操作路径改期 / 撤回 / 删除全部藏在「⋯ → 底部面板」两层之后
添加任务底部输入框 + 独立「添加任务」面板两条入口，标签/优先级只在面板里能改

4无障碍检查

WCAG 2.2 AA 逐项核对，新版全部通过。

  • 正文对比度：现状 TextMuted #B4B2A9 对白底仅约 2.2:1，不达标 → 新版 #75736C 达 4.9:1
  • 色彩传意：现状优先级仅靠色条 → 新版「色点 + 文字」，不依赖颜色单独区分
  • 触控目标：现状 24–28dp → 新版统一 ≥ 44dp
  • 焦点顺序：日期条 → 进度 → 列表 → FAB → 底栏，阅读顺序与视觉顺序一致
  • 点击区域与图标分离：勾选圈视觉 24dp，热区扩至 44dp
  • 所有图标按钮带 contentDescription，装饰性图标置 null
  • 状态不只靠颜色：完成 = 勾线 + 删除线 + 透明度三重提示
  • 系统字号放大到 200% 时不裁切：行高用 sp，容器用 dp
  • 深色模式：补 darkColorScheme，跟随系统切换（待 P2）
